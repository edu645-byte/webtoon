# 🍿 오늘 뭐 볼까? (What to Watch Today)

> **"좋아하는 웹툰이나 영화를 다 보고 난 후, 비슷한 감성의 다음 작품을 찾느라 시간을 허비하지 마세요!"**

`오늘 뭐 볼까?`는 사용자가 감명 깊게 본 인생작(영화/웹툰)을 입력하면, 작품 간 **장르, 감성/분위기 태그, 줄거리 핵심 키워드**를 정밀 분석하여 **0~100점의 유사도 점수**를 계산하고 가장 일치율이 높은 최적의 다음 작품을 추천해 주는 웹 서비스입니다.

---

## 🌟 핵심 기능

### 1. 영화 & 웹툰 메타데이터 관리 (`data.js`)
- 영화(넷플릭스, 극장가 인기작 등) 및 웹툰(네이버, 카카오 등)의 장르, 분위기 태그, 줄거리 키워드 데이터 제공
- 확장 가능한 오픈 API(TMDB, KOBIS 등) 연동 표준 데이터 규격 적용

### 2. 정밀 유사도 점수 계산 엔진 (`recommender.js`)
- **분위기/감성 태그 일치도 (40%)**: `#두뇌싸움`, `#사이다`, `#힐링`, `#다크판타지` 등 작품의 정서적 톤 비교
- **장르 일치도 (35%)**: SF, 액션, 스릴러, 판타지 등 장르의 자카드(Jaccard) 유사도 계산
- **줄거리 키워드 매칭 (25%)**: 시간여행, 복수, 꿈, 군주 등 핵심 소재 비교
- **0~100점 점수화**: 종합 점수를 직관적인 게이지 뱃지로 출력하고 일치하는 공통 키워드를 하이라이트

### 3. OTT 스타일의 모던 UI/UX (`index.html`, `style.css`, `app.js`)
- 넷플릭스/왓챠 감성의 세련된 다크 테마 및 글래스모피즘 디자인
- 검색어 실시간 자동완성 및 빠른 추천 칩
- 반응형 레이아웃 (스마트폰, 태블릿, PC 완벽 지원)

## 📂 파일 구조

```
프로젝트 5/
├── index.html        # 메인 웹페이지 마크업 (검색창, 필터 탭, 결과 카드 그리드)
├── style.css         # 다크 테마 반응형 스타일시트
├── data.js           # 영화 및 웹툰 메타데이터 데이터베이스
├── recommender.js    # 키워드/장르 자카드 유사도 점수 계산 엔진
├── app.js            # 검색 자동완성, 이벤트 처리 및 화면 렌더링 컨트롤러
└── README.md         # 프로젝트 설명서
```

## 🚀 실행 방법

별도의 서버 설치나 복잡한 설정 없이 바로 실행할 수 있습니다:

1. 파일 탐색기에서 `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge) 등의 웹 브라우저에서 바로 엽니다.
2. 또는 로컬 웹 서버(VS Code Live Server 또는 파이썬 `python -m http.server 8080`)로 실행하셔도 좋습니다.

---

## 💡 사용 방법

1. **인생작 입력**: 검색창에 내가 재밌게 본 작품(예: `인셉션`, `전지적 독자 시점`, `기생충` 등)을 입력하거나 아래 추천 버튼을 누릅니다.
2. **카테고리 선택**: `전체`, `영화만 보기`, `웹툰만 보기` 중 원하는 카테고리를 선택합니다.
3. **감성 태그 선택 (선택 사항)**: 원하는 분위기(예: `#사이다`, `#두뇌싸움`, `#힐링` 등)를 클릭하여 선택합니다.
4. **추천받기**: `유사도 점수 기반 추천받기` 버튼을 누르면 일치 점수 순으로 카드 형태의 추천작과 매칭 이유가 나타납니다.
